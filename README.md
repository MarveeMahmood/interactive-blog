# Interactive Blog

This is my project where I built a blog with HTML, CSS and JavaScript. The posts and comments come from the DummyJSON API.

Live site: https://marveemahmood.github.io/interactive-blog/

# Features

- See 10 blog posts on the home page
- Open a post and read its comments
- Write a comment
- Edit a post's title and content
- Delete a post

# Note

DummyJSON doesn't really save changes, so new comments, edits and deleted posts come back to normal when you reload the page.
